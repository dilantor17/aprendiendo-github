# 🚀 Aprendiendo Git y GitHub

## 👨‍💻 Presentación

Hola, soy **Dilan Santiago Torres Vera**, aprendiz de Análisis y Desarrollo de Software (ADSO).

Este repositorio fue creado como proyecto final del laboratorio de GitHub, con el propósito de documentar los conocimientos y habilidades adquiridos durante las actividades.

## 🎯 Objetivos

- Comprender qué es Git y GitHub.
- Aprender a crear y administrar repositorios.
- Practicar los comandos principales de Git.
- Trabajar con ramas y Pull Requests.
- Aprender a documentar proyectos utilizando Markdown.
- Desarrollar habilidades para trabajar en proyectos de software.

- Git
- GitHub

## 📚 Aprendizajes adquiridos

Durante este laboratorio aprendí a crear repositorios, clonar proyectos, realizar cambios, guardar versiones mediante commits, trabajar con ramas, fusionar cambios y crear Pull Requests.

## 📌 Conclusión

Este laboratorio me permitió conocer las herramientas básicas de control de versiones y comprender la importancia de Git y GitHub en el desarrollo de software.
